# BizReel Official Logo Assets

The app uses the official "BR" logo provided by the design team.

## Assets Source
- **Source File**: `assets/logo.png` (The exact image provided)

## Generated Assets
1. **App Icon**: `assets/icon.png` (1024x1024) - Direct copy/resize of source.
2. **Adaptive Icon**: `assets/adaptive-icon.png` (1024x1024) - Foreground centered with padding.
3. **Splash Screen**: `assets/splash.png` (2048x2048) - Logo centered on `#050508` background.

## Update Process
When the `assets/logo.png` is updated, run the generation script to refresh all native assets.
